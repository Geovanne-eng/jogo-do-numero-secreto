# Jogo do Número Secreto

O Jogo do Número Secreto é um jogo simples desenvolvido em HTML, CSS e JavaScript. O objetivo do jogo é adivinhar um número secreto gerado aleatoriamente entre 1 e 10.

## Funcionalidades

- **Interface de Usuário:** Uma interface amigável onde o usuário pode inserir seu palpite.
- **Verificação de Palpite:** Um botão para verificar se o palpite do usuário está correto.
- **Reinício do Jogo:** Um botão para reiniciar o jogo após adivinhar corretamente.
- **Feedback Visual:** Mensagens de feedback para informar o usuário se o palpite está correto ou incorreto.

## Tecnologias Utilizadas

- **HTML:** Estrutura da interface do usuário.
- **CSS:** Estilização da interface para torná-la atraente e responsiva.
- **JavaScript:** Lógica do jogo, incluindo geração do número secreto e verificação dos palpites.

## Como Jogar

1. Escolha um número entre 1 e 10.
2. Clique no botão "Chutar" para verificar se o número escolhido é o número secreto.
3. Se o palpite estiver correto, você ganha! Caso contrário, tente novamente.
4. Após adivinhar corretamente, você pode iniciar um novo jogo clicando no botão "Novo jogo".

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/Geovanne-eng/jogo-do-numero-secreto.git
   ```
2. Abra o arquivo `index.html` em seu navegador.
